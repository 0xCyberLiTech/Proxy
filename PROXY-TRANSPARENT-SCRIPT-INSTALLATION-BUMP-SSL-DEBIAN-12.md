- **Niveau 1 — Fondamentaux &amp; Principe d'Architecture :** Un **Serveur Proxy** agit comme passerelle intermédiaire de sécurité et de performance : en **Proxy Explicite / Sortant (Squid)**, il contrôle, journalise et met en cache les accès Web des postes internes ; en **Reverse Proxy (Nginx / HAProxy)**, il protège les applications internes derrière un point d'entrée unique (TLS, WAF, mTLS).
- **Niveau 2 — Repères Officiels (Ports IANA, Fichiers Debian &amp; Commandes de Validation) :** **Ports standards :** `TCP 3128` (Squid Forward Proxy) · `TCP 80 / 443` (Reverse Proxy HTTP/HTTPS) &nbsp;|&nbsp; **Fichiers Debian :** `/etc/squid/squid.conf`, `/etc/nginx/nginx.conf` &nbsp;|&nbsp; **Validation officielle :** `sudo squid -k parse` / `sudo nginx -t`.
- **Niveau 3 — Diagnostic d'Incidents &amp; Ingénierie Avancée :** **Diagnostic & Architecture :** Dans Squid, les directives `http_access` sont évaluées séquentiellement selon le principe du **premier match gagnant** : placez impérativement vos règles d'autorisation (`http_access allow <acl_lan>`) au-dessus de la règle de fermeture `http_access deny all`.

## <img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/icons/wire-crypto.svg" width="18" height="18" align="absmiddle" alt="" /> Voici un script Bash complet pour Debian 12 (Bookworm), Debian 13 (Trixie) & Debian 14 (Forky) qui :
<img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/glow-section-cyan.svg" width="100%" alt="" />

- Installe Squid et les dépendances.
- Configure Squid en proxy transparent HTTP + HTTPS (SSL Bump).
- Crée un certificat CA autosigné.
- Configure les redirections avec iptables

A présent créer un fichier nommé install_squid_transparent.sh vers /usr/local/ puis copier le code ci-dessous dans ce fichier install_squid_transparent.sh.

<!-- CODE-WINDOW-START -->
> [!CAUTION]
> <img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/glow-code-red.svg" width="100%" alt="TERMINAL // BLOC DE CODE" />
>
> ```bash
> #!/bin/bash
>
> # === Variables à adapter ===
> LAN_IF="eth1"     # Interface réseau locale
> WAN_IF="eth0"     # Interface vers Internet
> LOCAL_NET="192.168.1.0/24"  # Réseau local
> CA_DIR="/etc/squid/ssl_cert"
> SSL_DB="/var/lib/ssl_db"
>
> echo "[+] Mise à jour du système"
> apt update && apt upgrade -y
>
> echo "[+] Installation de Squid et des outils SSL"
> apt install -y squid openssl ssl-cert iptables iptables-persistent
>
> echo "[+] Création du certificat CA"
> mkdir -p $CA_DIR
> cd $CA_DIR
> openssl genrsa -out myCA.key 4096
> openssl req -new -x509 -days 3650 -key myCA.key -out myCA.crt \
>   -subj "/C=FR/ST=France/L=Paris/O=MonProxy/CN=MonProxyCA"
>
> chown -R proxy:proxy $CA_DIR
> chmod 700 $CA_DIR
>
> echo "[+] Création de la base de certificats SSL"
> mkdir -p $SSL_DB
> /usr/lib/squid/security_file_certgen -c -s $SSL_DB -M 4MB
> chown -R proxy:proxy $SSL_DB
>
> echo "[+] Sauvegarde de la configuration Squid existante"
> cp /etc/squid/squid.conf /etc/squid/squid.conf.bak
>
> echo "[+] Écriture de la configuration Squid"
> cat > /etc/squid/squid.conf <<EOF
> http_port 3128 intercept
> https_port 3129 intercept ssl-bump cert=$CA_DIR/myCA.crt key=$CA_DIR/myCA.key generate-host-certificates=on dynamic_cert_mem_cache_size=4MB
>
> sslcrtd_program /usr/lib/squid/security_file_certgen -s $SSL_DB -M 4MB
>
> acl step1 at_step SslBump1
> ssl_bump peek step1
> ssl_bump bump all
>
> acl localnet src $LOCAL_NET
> http_access allow localnet
> http_access deny all
> EOF
>
> echo "[+] Activation du forwarding IP"
> echo "net.ipv4.ip_forward = 1" >> /etc/sysctl.conf
> sysctl -p
>
> echo "[+] Configuration des règles iptables"
> iptables -F
> iptables -t nat -F
>
> # Redirection HTTP
> iptables -t nat -A PREROUTING -i $LAN_IF -p tcp --dport 80 -j REDIRECT --to-port 3128
> # Redirection HTTPS
> iptables -t nat -A PREROUTING -i $LAN_IF -p tcp --dport 443 -j REDIRECT --to-port 3129
> # NAT pour l'accès Internet
> iptables -t nat -A POSTROUTING -o $WAN_IF -j MASQUERADE
>
> echo "[+] Sauvegarde des règles iptables"
> netfilter-persistent save
>
> echo "[+] Redémarrage du service Squid"
> systemctl restart squid
> systemctl enable squid
>
> echo "[[OK]] Installation terminée !"
> echo "  Pense à déployer le certificat CA sur les clients : $CA_DIR/myCA.crt"
> ```
